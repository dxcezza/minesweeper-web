# Сплин Сапёр — веб-версия

Играть: https://dxcezza.github.io/minesweeper-web/

Сапёр-марафон в браузере, без сборки и зависимостей: HTML, CSS и JavaScript-модули. Отдельная от Godot-проекта реализация той же игры.

- **Сплин** — 5 полей подряд, время тает с 3:00, предметы (Ясность, Часы), Раскрытие, очки и комбо.
- **Классика** — одно поле одной из шести сложностей, секундомер, опция «Без угадываний» (поле решается логикой).

Управление: тап — открыть, долгое нажатие — флаг, тап по цифре — открыть соседей. Мышью: правая кнопка — флаг, колесо — зум, Esc — пауза, F11 — полный экран.

## Запуск локально

Модули не грузятся с `file://`, нужен любой статический сервер:

```bash
python -m http.server 8000
```

и открыть http://localhost:8000.

## Устройство

| Файл | Что внутри |
|---|---|
| `js/core/` | Логика без отрисовки: `board.js` (поле, флаги, аккорд, Раскрытие, предметы), `noguess.js` (генерация без угадываний и решатель, считается в `noguess_worker.js`), `config.js` (этапы, сложности, очки) |
| `js/session.js` | Забег «Сплина»: время, мана, счёт, комбо |
| `js/save.js` | Рекорды, статистика и настройки в `localStorage` |
| `js/boardview.js` | Поле на canvas: острова / блоки, анимации, частицы, жесты, зум и мини-карта |
| `js/palette.js`, `js/icons.js`, `js/blocks.js` | Оформление: пресеты цветов, векторные иконки, объёмные блоки |
| `js/audio.js` | Звуки и музыка на Web Audio |
| `js/ui/` | Экраны: меню, игра, классика, сложность, рекорды, настройки, обучение |

Раскладка рассчитана на ширину 720 и масштабируется под экран целиком (`#app` в `js/main.js`).
Звуки и музыка — `assets/sfx`, `assets/music` (mp3), шрифт — Oswald (SIL OFL, `assets/fonts`).

Выкладка — GitHub Pages из ветки `main`: достаточно запушить изменения.
